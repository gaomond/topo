## 入力
- 今回の変更一式（バックエンドとフロントエンド）
- `.agent-pipeline/05-review.md`（承認済み）
- `.agent-pipeline/03-impl-notes.md` / `04-test-report.md`

## やること
1. 変更内容を要約する。
2. 日本語のコミットメッセージ案を作る（件名＋本文。ユビキタス言語に沿う）。
3. 残課題・フォローアップを洗い出す。

## 出力
`.agent-pipeline/06-commit-ready.md` に書き出す。

````markdown
# 06-commit-ready
## 変更サマリ
## コミットメッセージ案
```
<件名>

<本文>
```
## 残課題
````

最後に「コミット可能」と要点を報告して終了する。
