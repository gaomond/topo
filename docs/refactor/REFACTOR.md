## 共通方針

- 既存 API と動作、DB スキーマを維持する。業務ルールは Domain、手順とトランザクションは UseCase、HTTP・DB の処理は各 Adapter に置く。
- 再確定の再送は US-11 の既存409で扱う。冪等性キーや成功応答の再現、競合専用の細かなエラー体系・汎用リトライは将来の検討事項とする。
- 同時参加・参加と開始は RS-05、同時確定と集計は [US-13](../story/13.md) のゲーム行ロックと同一トランザクションで整合させる。実 DB で競合を確認する。
- 状態取得には読み取り射影を使い、空間計算は [設計書](../DESIGN.md) に沿って PostGIS が担う。
