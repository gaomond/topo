# 01-spec.md — US-18: アプリ内のライセンス・データ出典の案内

> プレイヤーとして、アプリ内でライセンス表示と、地図・神社データの出典・加工方法・利用条件へのリンクを確認したい。利用しているデータとその条件を確認できるようにするため。
> 本仕様は1実装単位（US-18）分。Phase 2（実装）へ引き継ぐ。

リポジトリにはLICENSEとデータの説明資料があるが、アプリからはそれらを確認する入口がない。ゲーム作成画面と待機画面に案内を用意し、短いライセンス・出典表示から、既存の公開資料へ進めるようにする。

```text
ゲーム作成・待機画面の「licences」
  → ゲーム画面を保持したままダイアログを表示
  → コード・文書のライセンス／地図・神社データの出典と利用条件を確認
  → 詳細資料を別タブで開く、または閉じて元の画面へ戻る
```

## 1. 合意された仕様

### 1.1 入口とダイアログ（D1=A）

- 共通の「licences」ボタンから「Licences」ダイアログを開く。フッターの罫線を外し、小さなテキストの入口とする。専用ページへのSPA内遷移や、結果・ゲーム専用のURLは追加しない。
- 入口のフッターはゲーム作成画面と、参加済みプレイヤーの待機画面にだけ表示する。作成画面の設定読み込み・エラー時にも表示する。参加画面・プレイ画面・結果画面と、ゲーム取得中・取得エラー時にはフッター自体を表示しない。
- 入口は地図の帰属表示、ズーム・全体表示、確定・遊び方など既存の操作を覆わない位置に置く。小さい画面でも押せる領域と、読める文字サイズを確保する。
- ダイアログにはタイトルと「閉じる」ボタンを用意し、Escapeでも閉じられるようにする。開いたときにフォーカスを移し、Tab移動を内部に閉じ込め、閉じた後は入口へ戻す。背景のゲーム進行で入口がなくなった場合は、現在の画面へフォーカスを戻す。
- 表示中は背景のクリック・キーボード操作を遮断する。リンクや閉じる操作から、背景の位置確定・ゲーム作成などを誤実行しない。
- 内容が画面に収まらない場合は内部をスクロールできるようにする。390px程度の画面幅で文章・リンク・閉じる操作が使え、横にはみ出さないことを確認する。
- 既存の確定確認ダイアログ・US-19のウォークスルーとは重ねて開かない。待機中に案内を開いたままゲームが始まった場合、初回説明は案内を閉じた後に表示する。

### 1.2 アプリ内に表示する内容

| 区分 | 表示する内容 |
| --- | --- |
| topoのコード・文書 | All rights reserved、著作権表示、適用範囲と例外を記したLICENSEへのリンク |
| 地図・神社データ | `© OpenStreetMap contributors` の出典表示と、OSMの著作権・ライセンス説明へのリンク |
| データの利用条件 | 神社データにODbL 1.0が適用されることと、そのライセンス本文へのリンク |
| 加工・詳細説明 | 「地図・神社データの出典・加工方法・利用条件」として、既存のdocs/data-loading.mdへのリンク |

- topoの権利留保を、OSM由来のデータや依存ライブラリへ広げない。依存ライブラリにはそれぞれのライセンスが適用されることを短く添える。
- 加工方法やデータ投入手順をダイアログへ複製しない。既存資料からLua・SQL・スキーマ定義へ辿れる構成を維持する。
- 地図画像の配信と、集計用の神社データの取得・投入は別の仕組みとして扱う。アプリ内の出典案内によって、地図上の帰属表示を省略しない。

### 1.3 詳細資料へのリンク（D2=A）

| 内容 | リンク先 |
| --- | --- |
| topoのLICENSE全文 | `https://github.com/gaomond/topo/blob/main/LICENSE` |
| データの出典・加工方法・利用条件 | `https://github.com/gaomond/topo/blob/main/docs/data-loading.md` |
| OSMの著作権・ライセンス説明 | `https://www.openstreetmap.org/copyright` |
| ODbL 1.0本文 | `https://opendatacommons.org/licenses/odbl/1-0/` |

- 外部リンクは別タブで開き、そのことをリンク名または補助説明で伝える。`noopener noreferrer` を付ける。ゲームのURL・playerId・座標をリンク先のパラメーターに付加しない。
- アプリ起動時やダイアログ表示時にGitHubをfetchしたり、資料の本文をAPI経由で取り込んだりしない。リンクを選んだときに外部資料を開く。
- GitHubのmainブランチにある既存のLICENSE・データ説明を説明の正とし、これらのアプリ用コピーやオフライン用の文書配信は追加しない。依存ライブラリの資料は[US-22](22.md)で別途生成・同梱し、このダイアログから案内する。
- この仕様の確定時点ではLICENSE・説明資料に未コミットの変更がある。公開リリース前に、リンク先の資料と関連スクリプトが認証なしで読めることを確認する。リンクの公開確認前に公開済みとは記録しない。

### 1.4 地図とプレイ状態の維持

- 開閉によってURL・gameId・playerIdを変えず、作成フォームの入力やゲーム画面を作り直さない。プレイ画面をアンマウントしない。
- ダイアログ表示中も、開始済みのGPS取得・ライブ位置送信・状態ポーリングは継続する。ダイアログのために新しいGPS取得や位置情報の許可要求を開始しない。
- 開閉をUS-19の説明閲覧完了とみなさず、初回説明やGPS開始の条件を変更しない。既存の許可エラーや測位停止の契約も維持する。
- 待機中に開いた案内は、背景でゲームがACTIVE／COMPLETEDへ進んでも閉じる操作を残す。フッターは非表示とし、案内を閉じた後は最新状態の画面を表示する。完了時のGPS・ライブ送信停止はUS-14を維持する。
- プレイ・結果の地図上のOSM帰属表示とリンクを維持する。入口や追加UIで帰属表示を隠さず、ダイアログ内のOSM出典も読めるようにする。
- 外部リンクの `noreferrer` はそのリンクに限る。タイルへRefererを送れなくするグローバルなReferrer-Policyを追加せず、タイルの取得・キャッシュ・配信元は変更しない。

### 1.5 構成と既存機能の境界

- フロントエンドだけの実装とし、API・Controller・UseCase・Domain・ポート・DBは変更しない。ゲームの状態やGPSがなくても表示できる案内にする。
- 共通の案内は機能フォルダへまとめ、各画面に文面・リンク・ダイアログを個別実装しない。開閉はUI固有のローカル状態として管理してよく、新しい共有ストアやAPI呼び出しは不要。
- 文面・著作権表示はリポジトリのLICENSEとデータ説明に揃える。資料へのリンクは共通の定義から使い、画面ごとに異なる参照先を持たせない。

## 2. 受け入れ条件

- [x] ゲーム作成画面（設定読み込み・エラーを含む）と参加済みの待機画面から案内を開け、それ以外ではフッターを表示しない。
- [x] ダイアログにtopoの権利留保・著作権表示と、OSMの出典・ODbL表記があり、適用対象を混同しない。
- [x] LICENSE・データ説明・OSM説明・ODbL本文へのリンクが所定のURLを指し、別タブで安全に開く。
- [x] ダイアログの開閉やリンク選択で、背景の作成・参加・確定操作を実行しない。既存のダイアログ・説明と重ねて開かない。
- [x] フォーカス移動・内部のTab移動・Escape・閉じた後の復帰をキーボードで操作できる。
- [x] 開閉でURL・入力値を失わず、GPS・ライブ送信・ポーリングを余計に開始・終了しない。背景の進行と完了時の後始末を維持する。
- [x] 390px程度でも内容を読めて閉じられ、入口が地図の操作やOSM帰属表示を覆わない。
- [x] 案内のためのAPI・GitHub本文取得・GPS許可要求を追加せず、タイルへのRefererやキャッシュ設定を変更しない。
- [ ] 公開リリース前に、リンク先のLICENSE・データ説明と、説明から参照する加工スクリプト等を認証なしで閲覧できる。

## 3. テスト観点

テスト名は `test_Action_Condition_Result` とし、`frontend/tests/` にsrcをミラーして置き、実ソースをimportする。

- **表示・リンク** — 必要な表示区分、正確なhref、別タブの案内・target・relを検証する。GitHubへ本文取得のfetchをしないこと、APIやGPSに依存せず開けることを確認する。
- **開閉と操作遮断** — 作成・待機画面での開閉と、それ以外の画面・ゲーム読み込み・取得エラーでフッターがないことを検証する。Escape・フォーカス復帰・Tabの循環、背景操作の遮断、既存ダイアログ・説明との排他も確認する。
- **状態維持** — 入力途中の作成フォームと、待機からACTIVEへ進む実コンテナを使う。開閉で入力・URLを失わず、背景のゲーム進行で案内が消えず、GPS・ライブ送信・ポーリングの既存契約を維持することを確認する。表示中のCOMPLETED遷移では、閉じた後の結果表示とGPS停止を確認する。
- **実ブラウザ** — プレイ・結果の地図、390px幅、長い内容のスクロール、帰属表示と入口の重なり、キーボード操作を確認する。公開URLでは外部リンクを実際に開き、匿名で本文と加工方法へ到達できることを確認する。
- **バックエンド** — 契約変更はないため、新しいDomain・UseCase・Adapterテストは追加しない。既存の品質ゲートを維持する。

## 4. スコープ

### 含む

- 共通の入口・ダイアログ、自作部分とOSMデータの条件の区別、既存資料への外部リンク。
- 既存画面と測位・ポーリングを維持する結線、操作性・表示・リンクの検証。
- 出典資料・バックログから本仕様への参照の整合。

### 含まない（他ストーリー／将来）

- 新規API・専用ページ・本文取得API・既存のLICENSEやデータ説明のアプリ同梱、タイル配信元の変更。
- 位置情報の保存期間・削除機能、利用規約への同意フロー、認証機能。
- 遊び方の説明内容（US-19）、ゲームの確定・現在面積・参加確認の変更（US-12／US-20／US-21）。
- 依存ライブラリの資料の自動生成・同梱と閲覧リンクの追加（US-22）。topoの権利留保を依存物全体へ適用する表示は行わない。

### 判断ログ（3 Amigos）

| # | 論点 | 判断 | 理由 |
| --- | --- | --- | --- |
| D1 | 表示方法 | A。ゲーム作成・待機画面の入口から共通ダイアログを開く。 | 利用者の追加指定で表示先を限定。地図上のLeaflet・OpenStreetMap帰属表示は維持する。 |
| D2 | 詳細資料の提供 | A。GitHub上の既存のLICENSE・データ説明へ別タブで案内する。 | 利用者がAを選択。資料を二重管理せず、実際の加工処理へ辿れる。 |
| 適用対象 | ライセンスの区別 | topoのコード・文書、OSMデータ、依存ライブラリの区分を保つ。 | 各対象に異なるライセンスが適用されるため。 |
| 公開前提 | 外部資料の利用可能性 | リリース前に匿名閲覧で到達を確認する。 | 仕様時点のローカル文書を、公開済みのリンク先として扱わないため。 |
| US-22との整合 | 同梱資料の扱い | 既存のLICENSE・データ説明は従来どおり外部リンクとし、第三者ライセンスの生成・同梱と追加リンクはUS-22で扱う。 | US-22の合意に伴い、既存資料の複製を避ける契約と第三者資料の同梱を区別する。 |

### 前提・参照

- 地図上の帰属表示は[OSMの著作権・ライセンス説明](https://www.openstreetmap.org/copyright)、標準タイルの表示・Referer・キャッシュは[タイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)に従う。US-18の案内を既存の帰属表示の代わりにしない。

### 実装時の検証記録（2026-11-10）

共通フッターの入口と標準dialogを実装した。作成・参加の入力とURLを保持し、案内表示中の未読説明待機、既存GPS・送信・ポーリング継続、背景完了時の停止・結果表示をテストと実ブラウザで確認した。390px幅と通常幅で表示・キーボード操作・地図帰属との非重複を確認済み。全5品質ゲート成功。2026-11-10に独立レビューで指摘なし承認。バックエンドbuildはUP-TO-DATE、フロントエンドは31ファイル・256件成功。実ブラウザは実API・実Leafletと検証用GPSを使用し、実GPS・端末別OS許可・公開先のタイルRefererは未検証。

公開前条件は未達のまま残す。匿名事前確認ではmainのLICENSEが404、データ説明は出典追記前だった。アプリからの別タブ操作は確認したが、利用者のブラウザでの閲覧を匿名公開確認とは扱わない。資料をmainへ反映した後、本文と関連Lua・SQL・スキーマ定義への匿名到達を再確認する。

同日の追加指定により、フッターの入口をゲーム作成・参加済みの待機画面に限定した。参加・プレイ・結果・ゲーム読み込み・取得エラーではフッターを表示しない。待機中に開いた案内は開始後も閉じられ、GPS・送信・ポーリングと初回説明の既存契約を維持する。フロントエンドの4品質ゲート（31ファイル・256テスト）とバックエンドbuildが成功（バックエンドはUP-TO-DATE）。実ブラウザで作成・待機の入口と開閉、結果画面のフッター非表示、地図のLeaflet・OpenStreetMap帰属表示の維持を確認した。この追加変更は初回の独立レビューの対象外。


### 権利表記・表示の改訂（2026-11-10）

利用者の指定で、自作部分をAll rights reservedとし、OSMデータと第三者コードには広げない。適用範囲と再生成用の資料・コードのMIT例外はルートLICENSEを正とする。入口は`licences`、ダイアログは`Licences`。`topo`・`Map data`・`Third-party software`の3区分で簡潔な表記とリンクを配置する。本文は「使用ライブラリ」と「UIコンポーネント」から開く。表示対象、背景の状態保持、Escape・フォーカス、地図上の帰属表示の契約は維持する。
